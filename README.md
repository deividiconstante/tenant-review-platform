# Tenant Review Platform

A full-stack web application that allows tenants to review landlords and rental properties based on cleanliness, safety, value, and overall condition.

## Tech Stack
- Java
- Spring Boot
- Thymeleaf
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap

## Features
- Tenant property reviews
- Landlord feedback
- Rating system
- Search functionality
- Google Maps API integration
- Dynamic page rendering with Thymeleaf

## Project Goals
This project was created to practice full-stack web development and build a real-world style application using Java and Spring Boot.

## What I Learned
- MVC architecture
- Backend and frontend integration
- Database design and MySQL integration
- Dynamic rendering with Thymeleaf
- Working with external APIs such as Google Maps
- Structuring a full-stack Java web application

## How to Run
1. Clone the repository
2. Open the project in IntelliJ IDEA
3. Configure the MySQL database
4. Run the Spring Boot application
5. Open the browser and access the local server
